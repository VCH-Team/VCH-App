# 3D Tank Simulation

Desktop application for tank heating/cooling simulation with a 3D viewer and report.

## Structure
- physics/ — simulation engine (owned by ME team)
- io/ — UI and rendering (owned by CE team)
- materials/ — property tables (shared, ME lead owns)
- docs/ — design and decision records

## Status
Pre-alpha. See docs/IMPLEMENTATION_PLAN.txt for the plan.
